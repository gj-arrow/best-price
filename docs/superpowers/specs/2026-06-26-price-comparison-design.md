---

## 📋 Обзор проекта

Сервис сравнения цен на технику с поиском по топ-агрегаторам магазинов. Пользователь вводит название товара — получает лучшие цены с прямыми ссылками на магазины.

### Цель
Получить максимально быстро наилучшую цену товара (в основном техники), чтобы не лазить по разным сайтам и не искать каждый раз одно и тоже.

### Функциональные требования
- Поиск товаров по названию
- Вывод топ-3 лучших цен
- Отображение минимальной и максимальной цены
- Прямые ссылки на товары в магазинах
- Архитектура под партнёрские ссылки (монетизация)

## 🎨 Frontend Design

### Главная страница
- **Макет:** Крупный поисковый блок по центру (Google-style)
- **Логотип:** Сверху по центру
- **Популярные запросы:** Снизу (опционально)

### Страница результатов
- **Топ-3 карточки:** Горизонтально в ряд
- **Лучшая цена:** Выделена цветом/размером, значок "Лучшая цена"
- **Блок мин/макс:** Отдельно под карточками
- **Кнопки:** "Перейти в магазин" на каждой карточке

### Анимации
- Плавное появление результатов (fade-in)
- Hover-эффекты на карточках (поднятие + тень)
- Анимация загрузки (скелетон/спиннер)
- Микро-анимации кнопок

### Цветовая схема
- **Фон:** Белый / светло-серый
- **Акцент:** Синий/фиолетовый (доверие, технологии)
- **Цена:** Зелёный (выгода)
- **Кнопки:** Градиент

### Хедер
- Логотип слева
- Поисковая строка в центре (уменьшенная)
- Справа: История, Избранное, Профиль

### Карточка товара
- Название товара
- Цена (крупно, зелёным)
- Логотип магазина
- Кнопка "Перейти в магазин"
- Значок "Лучшая цена" для топ-1

## ⚙️ Backend Design

### Парсеры магазинов
- **Паттерн:** Единый интерфейс `IScraper` + класс на каждый магазин
- **Магазины:** Onliner.by, Wildberries, Ozon, Shop.by, Home.1k.by, 360shop.by
- **Подход:** Гибридный (API где есть, парсинг где нет)


### Обработка ошибок
- **Таймаут:** 5 секунд на каждый магазин
- **Graceful degradation:** Продолжаем без упавших магазинов
- **Логирование:** Все ошибки пишутся в лог
- **Результат:** Возвращаем даже если не все магазины ответили

### База данных (минимальная схема)
```sql
-- История поисков
CREATE TABLE searches (
    id SERIAL PRIMARY KEY,
    query VARCHAR(255) NOT NULL,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    user_id INTEGER -- NULL для анонимных
);

-- Найденные товары
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    search_id INTEGER REFERENCES searches(id),
    name VARCHAR(500) NOT NULL,
    price DECIMAL(10, 2) NOT NULL,
    store VARCHAR(100) NOT NULL,
    url TEXT NOT NULL,
    cached_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### API Endpoints
```
GET  /api/search?q={query}     -- Поиск товаров
```

## ✅ Критерии приёмки

1. Поиск возвращает результаты за ≤ 10 секунд
2. Топ-3 цены отображаются корректно
3. Ссылки ведут на правильные страницы товаров
4. Анимации плавные (60 FPS)
5ы. Адаптивная вёрстка (mobile/desktop)
